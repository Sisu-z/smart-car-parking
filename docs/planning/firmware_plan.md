## 2. 待整合的具体差距与暂定数据流

目前最直接的联合候选沿用 [硬件事实库](../../01_hardware_source_of_truth.md) §1 的**厂家参考**：A=PB1/TIM3_CH4、PB14/15；B=PB0/TIM3_CH3、PB13/12；E1=PB6/7/TIM4、E2=PA0/1/TIM2；USART1=PA9/10。A/B、E1/E2 与车身左/右轮的实际对应、正反极性必须由实物记录，不能从示例代码猜。厂家 HAL 的 `Set_PWM` 曾把 A/B 的 CCR3/CCR4 写反；联合适配层要按实物接线和波形逐通道复核，见 [03/B02](../../03_motor_encoder_pid_bringup.md)。

现行 PA6/TIM3_CH1 舵机使用 50 Hz，而电机 TIM3_CH3/CH4 目标 10 kHz；同一 TIM3 共享 PSC/ARR。**候选**把舵机信号迁到 PA8/TIM1_CH1，PA6 可留给经校准的 ADC 电源采样。这样 TIM1 不再能同时按既有 `04_firmware_module_plan.md` 示例充当 100 Hz 周期定时器：先从 1 ms SysTick 派生 10 ms 控制请求，实测调试 GPIO 周期与最坏时延；达不到登记的控制预算，再比较专用定时器，不能只改注释。PA8 改线要断电且核实舵机信号线实物连接；`test02-motion` 的构建并未证明实物迁移成功。

联合工程建议的内部数据流（接口尚未冻结）：

```text
UART/未来 RDK 链路 → 有界接收队列 → v0.1 命令/版本化车辆命令提案
                        → 共用状态与故障门控 → 左右目标快照
TIM2/TIM4 原始 CNT + 实测 dt → 各轮 delta/count total → 有效 RPM
                        → 各轮 P/PI → motor A/B 归一化 duty → HAL 真值表输出
舵机目标 pulse_us → TIM1 PWM → 机械标定表 δ_est(rad)，仅为估计值
两轮位移 + δ_est + 标定几何 → 局部位姿增量/有效标志 → 遥测快照
```

`Motor`、`Encoder`、`PID` 各实例化两份；`Bench` 的超时、故障锁存、无旧目标恢复和换向静止规则可复用，但不能简单复制两套独立 `Bench` 后让一轮超时而另一轮继续驱动。需要一个**共用**使能/故障层先输出安全快照，再交由薄 HAL 适配写各通道；控制 ISR 不解析命令、不格式化/等待 UART。`coast`（IN1=IN2=0、PWM=高）只请求高阻，STBY 参考接法常高，不能称为硬件急停或停稳。上层收到停止请求与物理停稳必须分别上报。

## 3. 分关卡实施，失败即退回上一个已证实状态

每关卡产物写明板版本、源提交、引脚/接线、供电、工具、原始波形/计数和通过阈值；阈值在测试前由相应审核者设定，不能见结果后放宽。阶段中的文件名是**后续实现落点提案**，不是本轮新增代码或接口冻结。

| 关卡／可实现改动 | 输入 → 输出（单位） | 前置与验证、通过条件 | 失败与回退 |
|---|---|---|---|
| F0 静态与无电机信号。受保护的 HAL 集成副本 + `board_config`/HAL adapter，逐项接入 TIM1/2/3/4、GPIO、USART；复用 `Motor` 与 `Command`，不搬运厂家整包 | 标注过的引脚/板版本 → A/B PWM 频率 Hz、舵机高电平 μs、E1/E2 原始 CNT | 电源窗口确认可上电范围后，**电机断开**；示波器/逻辑分析仪核 PB1/PB0 10 kHz、PA8 50 Hz/1500 μs、方向默认电平、串口收发与调试 GPIO 的 10 ms 周期。无仪表只记“未验证”，不能放行电机。 | 任一通道/供电错即断电，退回 `test01` 回中或禁能固件；不得靠接电机找信号。 |
| F1 一台电机开环 + 一个编码器。`motor` + `encoder` 与现有单路 `bench`；先 A/E1，再在相同流程下 B/E2 | 有界 duty `[-0.10,+0.10]` **仅为初测软件限幅提案**、原始 `uint16` CNT → 实际 PWM/方向、`delta_count`、累计 count、电压 V/电流 A | 电源/电机精确电流证据与限流条件经独立审核；车轮架空、一次只接一路。按 [B01～B05](../../03_motor_encoder_pid_bringup.md) 正/零/反短时测，手转正反多圈和 16 位回绕；记录 A/B↔左右、E1/E2↔轮位及极性。接受：电流在预定阈值内、正向命令和经修正 count 同号、零命令进入指定真值表状态。 | 电流/温升/压降/方向异常立即物理断能；退回 0 duty、raw count 和单路配置。10% duty 不保证安全电流。 |

| F3 每轮 P→PI。两份 `PidController`、共用状态/故障门控；保留当前 v0.1 单路台架命令，双轮目标仅作为新版本提案 | 有界目标 `rpm_L/R`、测得 `rpm_L/R`、`dt_s` → 有界归一化 duty，实际应用 duty/积分状态 | F1/F2 与停止策略通过后，先 `Ki=Kd=0`、低速 P；方向正反馈立即停。再小步 PI，验证饱和解除、disable/fault/换向复位、超时锁存与断连不恢复旧目标；控制周期不受 20 Hz 遥测影响。增益和最大 RPM 在实物标定前均未设。 | 振荡/反向/积分累积即退回开环与零增益；不能复制仿真或厂家参数。D 项只有重复证据需要时另提。 |
| F4 舵角与底盘运动。`servo` 标定/vehicle 映射/局部 `odometry` 候选，仍由状态门控 | 车辆有界 `v_mps`、转向 `δ_rad` 或曲率 `κ_1pm`（**接口提案**）→ 左右目标 RPM、舵机 pulse_us；编码器 → `Δx_m, Δy_m, Δyaw_rad` + 质量标志 | 实测轮半径 `r_L/R`、驱动轮距 `w`、轴距 `L`、舵机 pulse→轮角/死区/回差、最低可控速度和停止包络。仅在两侧为独立驱动且几何适用时可暂用 `v_L/R=v(1∓κw/2)`、`RPM_i=60v_i/(2πr_i)`、`yaw_rate≈v tan(δ)/L`；先架空再有限空间低速直线/圆弧/倒车，外部量尺比对。PWM 脉宽只代表命令，**不是**车轮角度反馈。 | 几何/回差/打滑不合模型即停在两轮低速台架；里程增量标无效或扩大不确定度，不宣称已定位，更不据仿真半径定制地图。 |
| F5 RDK 有界链路与故障闭环。传输适配与车辆状态/反馈提案；底层 motor/encoder/PID API 不随传输改写 | 版本/会话/序号/时限/校验的车辆目标 → 接受/拒绝、执行状态、实际速度、停止请求/停稳、故障 | 先在主机用旧包、重放、乱序、跨重启、断线、坏校验、拥塞和传感器失效注入；再经有界实车范围验证。最终 UART/CAN 由 RDK/电气两窗给出的电平、时延、噪声与连接证据选。VOFA+ 仅供调试，不是安全条件。 | 任一旧命令恢复运动或断连不失能即退回本地单机台架；正式链路/故障枚举须经总监更新契约与独立审查。 |

F4/F5 属 M2；F0～F3 对应 M0/M1。里程计是相对估计且会漂移；没有外部位姿和空闲空间证据时，底层能够转弯也不代表自主循迹/泊车可行。当前寝室约 1～1.5 m × 2～3 m、车宽约 15 cm 只给约束范围；真实转弯/停止包络未测前不承诺道路或车位布局。

## 4. 总监可集中索取的最小实物证据包

为避免反复拆装，建议一次请用户提供：① D153 正反面清晰丝印、A/B 与 E1/E2 接线、STM32 板与舵机信号线当前位置；② 两台电机、编码器、舵机、电源/稳压模块的标签及**当前台架**电源电压/电流标注、接地/STBY/断电方式（正式电源未购，不沿用旧“12 V 电池/5 V 电源”记录）；③ 可用万用表、限流电源、示波器/逻辑分析仪及可架空车轮的条件。资料可由电源窗口统一审查，隐私原图不上传公共仓库。精确电机启动/堵转电流、编码器 VCC/CPR 与供电树缺证据时，只阻塞通电/测速/闭环结论；F0 静态代码表、主机双路故障测试可继续。

最先两个低风险检查：

1. 只读核实当前源码与接线图：把 A/B ↔ 左右、E1/E2 ↔ 轮位、TIM3/TIM1 共用资源、STBY 状态列成一张待签表；拍照和断电连通性检查后才能定映射。
2. 在电脑端用现有 C 测试框架增加**候选联合状态机**的双轮原始计数回绕、只一轮超时→两轮禁能、反向换向/旧包拒绝用例；此检查不触碰设备，也不将 `test02` 的百分比命令混进 v0.1。

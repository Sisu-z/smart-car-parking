## 2. 最小电源树与线束候选（不冻结连接器/电池）

候选A：单个成品车载电源，正端近源保险及防反接/总开关后分支；负端设分配点。电机、舵机与计算平台用不同供电支路，**这只是分支解耦，不是电气隔离**。既有D153先作为双驱动候选保留，不批准它同时承担整车5 V输出。

| 功能线束 | 候选去向 | 接线设计与采用条件 |
|---|---|---|
| P0源端 | 成品电池/BMS或已核验台架源→近源保险→总开关→分配 | 电池化学体系、串数、满电/低电、放电能力、配套充电器及储存条件未定。保险不能用来故意短路试验；DC开关/连接器需有适当额定值。 |
| P1驱动 | 分配→支路保护→独立人工断能器→D153 VM→A/B电机 | 动力线成对、固定防拉；不走面包板/未经额定核验的杜邦跳线。断能器和支路保护按电流、直流分断能力及回生路径审查。 |
| P2计算 | 分配→独立成品5 V稳压模块→合适Type-C线→X5→USB相机/串口 | 要求整条模块/接口/线材路径支持官方5 V/5 A供电要求；另核负载瞬态、纹波、热及USB共享限额。不能凭“USB-C/PD”字样保证5 A，也不把9/12 V注入5 V板端。 |
| P3转向 | 分配→可切断执行器支路→符合型号的成品稳压/BEC→舵机 | 电压和峰值未知，不能先定5 V；独立于X5轨。机械窗口给安全转角/卡滞范围，禁止以顶住限位测堵转。 |
| P4逻辑/编码器 | 经审查的逻辑稳压源→STM32核心板、D153逻辑/编码器允许入口 | 首选核现有D153低功率轨是否可复用，再决定独立模块。D153内部轨与VM耦合未知；未经原理图核对，不外部强灌其3V3/5V。只能有一个供电源驱动同一轨。 |
| S1控制/编码器 | STM32↔D153/GMR/舵机 | 标端名、版本、电平和方向；电源回路与信号分开布置，信号携邻近地回路。必要缓冲/电平转换须核输出形式、速度和断电容忍后选模块。 |
| S2通信/调试 | X5↔STM32；ST-LINK/CH340仅调试 | UART只作为条件候选，不冻结脚位。分别核TX高低阈值、USB串口实际电平、各端断电行为；不能把两端5 V电源并联。 |

候选B：X5先用厂家规定的独立适配器，执行器另用限流台架源，分开验证再车载集成。它能提前测计算负载，不能宣称已解决便携整车供电。是否具备这些电源由总监问用户，不能按已拥有处理。

共地采用低阻分配、动力回流不串过MCU/编码器细线；信号线的参考地保持连续。若D153 VM切断导致其逻辑掉电，而MCU/X5仍通电，GPIO/UART可能反灌，须通过实板路径核查与有断电保护的缓冲/隔离等候选解决；串联电阻本身不证明安全。USB供电、CH340 VCC、ST-LINK目标电压引脚分别识别，任何供电组合都要检查“只开一端”状态。不得通过切断共地实施急停。

物理断能应覆盖两电机和舵机的执行器能源；计算平台可保留电源用于报告故障，但前提是信号不能绕过断能反向供能。GPIO控制STBY/外部看门狗只是可评审增强，不能替代独立人工断能。**断能后仍可能滑行、失去转向保持力；不得承诺立即停稳。** 回生、线束电感及电容储能仍需评估；不能把“有TVS/BMS”当已验证，钳位上限/动态特性须与全轨边界匹配，普通降压源未证明可吸收回灌。

## 3. 负载和余量：现在能算什么

| 轨 | 典型 / 峰值输入 | 本轮可用计算与门槛 |
|---|---|---|
| VM | 两电机空载、带载、启动和故障电流均UNKNOWN | 分别记录A/B每路电流和同时运行。每路满足驱动工作/脉冲条件，合并损耗满足实板热条件；电源输入电流不等于PWM期间绕组电流。 |
| X5 5 V | 适配器要求5 A已知，实际启动/CPU/NPU/USB总负载UNKNOWN | 官方供电能力包络为25 W，不是典型耗电。端口给相机/串口的耗电已包含在板输入总测量内，不重复相加；不默认USB每口1 A可同时满载。 |
| 舵机轨 | 静止/转向/负载瞬态UNKNOWN | 按型号和预定机械负载验证；动态电流、线压降及对X5轨扰动一起记录。 |
| 逻辑轨 | MCU核心板、D153逻辑、GMR及调试负载UNKNOWN | 核核心板稳压路径，避免两只稳压输出并联；若用板载LDO，检查压差×总电流与实际散热。 |

计算模板（`DESIGN`，不能填模拟电机参数）：

- 电池满电：`V_full = 串数 × 单节最高充电电压`，各值来自选定成品数据页；`V_VM,max = 满电/源容差上界 + 实测回生/线束瞬态`，应在芯片工作上限内保留可解释余量，绝不触及绝对最大。低电/压降也要同时满足电机所需性能、稳压输入下限与压差。降压芯片的最低输入值不保证其在5 V输出满载时仍稳压。
- 电源输入估计：`I_source = I_motor_bus + Σ(P_reg_output / (η_min × V_source,min))`；效率取模块相应负载/电压数据，不猜90%。持续与峰值分别算；不能用持续和瞬态的混合平均掩盖重启。
- 线损：`ΔV = I_peak × 回路总电阻`，包括来回线、保险/开关/插头；`V_load,min = V_reg,min − ΔV − 动态跌落`。在负载端测量合格窗，不能仅测模块空载输出。温升/纹波上界来自最坏负载与环境证据。
- TB6612热：按两路电流及数据页相应温度的导通损耗、开关损耗合计，结合实际板散热复核；没有实板热数据不宣布1 A/路持续通过。保险额定/时间曲线须兼容启动又保护最弱线束，**不能指望保险在10 ms内保护芯片，也不能把电源限流等同逐路电流闭环**。
- 续航：`t ≈ 可用Wh / 平均总W`；可用容量/截止条件、任务时长和总W均未定，当前不报续航。新增负载由系统窗口提供数量/模式，机械窗口给安装空间/散热条件后重算。

D153可继续保留为资料和受控单路候选；满足电压、电平、每路电流、双路热与断能门槛后才考虑正式复用。如果所需负载或故障电流超出可保护包络、热/压降不合格、保护或断电行为不能闭合，提出有电流限幅/测量且电压余量适合的成品驱动替代；不自行换型。X5独立稳压或舵机独立BEC也只按这些失败证据触发选型。

以下均为待适配候选，不是安装指令：

- **计算/控制层**：X5 使用现有孔位匹配的支柱或独立可拆绝缘托板，朝向以 USB、供电插头、TF、调试口能操作为准；预留插头本体、弯曲与手指操作空间，按实物量，不只量 PCB。驱动板/STM32 与底板绝缘，避开连杆/轮胎扫掠；通风散热区域上方不堆电池和线缆。所需散热器/风扇高度和功耗交系统/电源窗口核实。
- **电池占位**：先以电源窗口给出的候选长×宽×高、质量和接头方向做纸样占位；优先低、靠近车体纵向中心且不挡转向/断能位置。电池尺寸未到位不定承载板层高；电源安全决定前不定绑带/电池盒规格。新增负载会改变轮胎压缩、重心和停止距离，装载后必须重验。
- **相机候选 A**：已有固定孔位上的短支架，调俯仰后锁紧；刚性、易复位，优先做基线。**B**：短 L 支架/长孔配垫片，允许少量高度和俯仰调整；须核现成孔、螺纹、壳体夹持面。**C**：夹具临时采样，防滑与防坠，只适合静态比较。单点胶粘/软绑带承受 USB 拉力会漂移，不作为米制定位最终安装。均不假设 3D 打印、钻床或新工具已有。
- **线缆与维护**：相机线先在车体固定点卸载拉力，留受约束的插拔余量，不把插头当固定件；线束不跨连杆、不接触轮胎、不拖地。线长/电磁隔离与接线由电源窗口决定。拆相机不应牵动 X5/驱动板；断能装置始终可触及。螺丝长度核实际堆叠和厂家要求，不照抄案例 M3 数字。

实施顺序提案：断电测量/现有装配检查 → 纸样占位 → 候选静态视野比较 → 经授权试装、核干涉与维护 → 锁紧并登记安装版本 → 标定/独立复核。相机参考刚性底板；高而细的支架会增加挠动。锁紧/搬运/插拔前后用同一静态测点比较像素位置和米制残差；重复性误差必须纳入算法误差预算，未定预算则只报告差异。

## 3. 运动与车身包络：参数化检查

计算提案用后轴中心作几何参考，+x 前、+y 左；**这不是冻结实物 base_link 原点**。量得轴距 `L`、前悬 `f`、后悬 `b` 后，矩形范围为 `x∈[-b,L+f]`、`y∈[-w/2,w/2]`，总长 `ℓ=L+f+b`。`w` 应包住允许转向范围内轮胎、支架、插头、线缆，而非只用底板宽。非对称凸出应登记实际角点/轮廓；保守矩形可先离线检查。

理想无滑移阿克曼仅作初筛：安全范围内的等效车轮转角 `δ` 对应后轴路径半径 `R=L/tan|δ|`。舵机角/脉宽不是 `δ`。前轮内外角若能量得，左转时分别推算 `R=L/tanδ_in+t_front/2`、`R=L/tanδ_out−t_front/2`；明显不一致提示连杆/测量/模型问题，不能随意平均掩盖。真实左右与前后退的半径必须后续独立测量。

| 几何初筛 `[DESIGN]` | 用途与限制 |
|---|---|
| `R/L` 在等效转角 20°/30°/40° 时约 2.75/1.73/1.19 | 仅无量纲敏感性示例，均不是本车已能达到的转角；轴距和安全角两者缺一就没有实车半径 |
| `r_out = sqrt(max(L+f,b)^2+(R+w/2)^2)` | 保守矩形恒曲率旋转的最外角半径；含前后悬长，不能拿 `2R` 当车身转弯直径 |
| `min(W_free,H_free) ≥ 2(r_out+m)` | 完整圆周扫掠放进矩形的充分几何条件；不是 U 弯/多次调整泊车的必要条件，更不保证安全观察/控制 |
| 直通道 `B ≥ w|cosθ|+ℓ|sinθ|+2(e_y+m)` | 航向误差 θ 会把车长投影到路宽；零误差/仅口述宽时下限为约 0.15 m 加余量，不能作为最终车道宽 |
| 车位净宽/深大于停稳车身包络与误差余量 | 必须同时验证入口跨越、侧向/尾部扫掠和出库准备空间；“静态放得下”不等于能倒进去 |

`W_free/H_free` 是扣除家具、边界、人工断能通道后的真正可用区；纸面空间上限不能当空闲场地。`m` 是确认后的安全间隙，`e_y` 是横向误差上界，均待定。先让算法窗口用实测区间检查 1×2、1.5×3 m 两端及中间实际场地：道路曲线、90°方向过渡、近距离入库、出库、起步车位不可见的搜索；输出每种机动的扫掠极值、最小边界间隙和失败点。不定车道数/最终布局，不默认为原地直角转弯。

未来扫掠检查须加入转向过程的轮胎凸出、模型/定位误差与停止包络。离散采样间的车身点位移可按 `Δs + ρ·Δψ_total` 保守界定（Δs 为累计路程、Δψ_total 为累计绝对航向变化、ρ 为参考点到最远角点距离），据此细分或膨胀；不能以端点相消后的 yaw 差代替累计转动，当前代码单点碰撞未实现这项保证。沿运动方向的最新有效空闲距离至少覆盖 `|v|τ + d_stop + e_long + m`：τ 包含观测龄期和停止请求延迟，`d_stop` 为请求生效后实测停稳距离。弯道/倒车必须按扫掠方向检查，未知盲区不计空闲。参数不足时只保留候选路径。

## 4. 相机高度、俯仰、覆盖与标定

90° 标称可能是水平、垂直或对角，不能代入水平/垂直公式。先核型号、图像分辨率/裁剪、对焦状态、实际 H/V 视场、曝光延迟；由静态实拍登记近边、远边、左右界与被底盘/线缆遮挡区域。

针孔/平地初筛：光心高 `h`、向下俯仰 `β`、垂直视场 `φv`，中心纵向截面的地面范围为 `d_near=h·cot(β+φv/2)`、`d_far=h·cot(β−φv/2)`，要求 `0<β−φv/2<β+φv/2<90°`；距离自光心地面投影算，不自车头算。上边跨地平线时不存在有限远界，下边指向后方时近界公式也不能直接套用。畸变/遮挡/分辨率使实际可识别范围小于理想射线范围；提高安装不保证末端能看清。

每个候选安装先用已有相机、车辆固定且电机动力隔离的静态样本比较，采样供电/连接由获授权执行者确认，本轮只写方法：

| 姿态/场景 | 要看什么 / 留什么证据 |
|---|---|
| 道路直段、左右曲线的近/远位置 | 两边界可见段、近场断线、车头遮挡；原图和光心/车体参考位置 |
| 车位入口偏左/中/右、斜视与车位出视野 | 普通 U 形三边/入口的可见与不可见字段；不能只保留成功图 |
| 接近、换向准备、倒库入口/中段/末端、出库 | 分别检查任务目标线与实际运动方向通路；前向相机看到前方不证明倒车后方安全 |
| 地砖/反光/阴影、遮挡、无车位 | 误线/未知空间；另一个房间或会话留作独立验证 |
| 同一静态点在插拔/搬运复位前后 | 安装重复性、USB 拉力/支架挠动；安装变化则新 `mount_id`，重验外参 |

复用 `tools/calibrate_camera.py`（至少 6 张不同视角只是工具下限）、`templates/GROUND_PROFILE_TEMPLATE.json`、`offline.slot_cli`，不另写投影工具。固定安装、真实格尺寸和相同分辨率求内参；离线测至少 4 个不共线地面点及像素对应，覆盖实际分析区域；**留独立点检查尺度/方向/残差**，四点完美拟合不算准确。登记光心位置/俯仰/朝向、相机/安装/标定版本；手持图可做像素测试，不能沿用固定外参。棋盘/测点只作离线标定，不成为运行定位答案。

固定单相机先作最小基线。若倒车扫掠或搜索必须通过的区域持续不可观测，记录缺口再比较调整固定角度、云台、镜面或第二相机：调整影响道路远近场；云台需曝光时姿态/回差与外参；镜面现有投影不支持；双相机增加安装/供电/时间关系。不能用历史已见空地或人的观察冒充实时车载安全能力；观测缺口未解决不批准关联自主动作，也不改变随机找位目标。

## 5. 可收纳场地：先比较材料行为，后选布局

| 项目 | 整张可卷 | 拼接 |
|---|---|---|
| 几何/视觉 | 内部无拼缝，线连续；卷曲、翘边与反光待验证 | 接缝台阶/缝隙、错位会影响车轮和线；重拼后坐标可变 |
| 收纳/搬运 | 卷筒长度取决于卷向，仍至少等于该方向片材幅宽；收纳位置须量 | 单片大小可适应收纳；板厚/重量、定位与组装成本须核 |
| 固定/平面 | 需证明铺平、防滑且固定方式获许可；不能默认胶带可贴地 | 需证明片间不滑移/翘边、不产生视觉伪线；不预设拼接件 |
| 可逆探索 | 可移动普通线的临时片材；不先打印最终道路 | 小片试拼，移动普通线；接缝尽量避开关键弯道/车位入口只是提案 |

先在已有或获准借用的少量材料上比较平铺、收纳再铺、线对比/反光、轮径相对缝隙与接缝高度；有运动授权后才做接缝过轮验证。接缝使车体俯仰改变，会使固定平面映射失准，不能只查车轮能否过去。回传可用净区、地面类型、铺设限制、最大可收纳长宽厚和搬运方式，由总监判断是否需材料采购。两种方案未冻结；场地若只支持子关卡，明确剩余验证场地缺口，不据此降级目标。

总监集中向用户索取一次最低成本资料包，不要求用户填技术模板。工具不足时如实缺项，不买工具补齐：

| 静态 `ℓ,w,L,f,b`、前后轮距/轮径、离地高度 | 全车断电且稳定放置；直尺/卷尺量轴心投影和最外凸出，各读两次；回传数值、单位、读数分辨率、俯视+侧视带尺图。轮胎转向最大包络暂缺，不扳舵机齿轮 |
| A/B 到物理轮、舵机/连杆/孔位/螺丝与线缆 | 断电沿已有线束查看标签、俯视/底面局部照片；不拆带风险的已装件，不猜轮位；标出可见干涉与可操作接头 |
| 相机型号/壳体/接口、X5 与候选安装空间 | 标签、镜头和现状照片，量壳体及插头凸出；可用工具/现有支架库存一起说明。无相机固定则记录未固定 |

转向中心与限位分两阶段：本轮只能断电查看直行时轮位/连杆装配证据，**不强行回转舵机，不凭 1500 us 判轮正，也不扫到机械端点**。未来须先核舵机型号、安全供电/电流观察、电机动力隔离、稳定支撑、可立即断能及单独授权；从已确认安全状态小步检查轮角、左右对称、回差与干涉，发现阻力/异常电流立即停止，在机械端点之前登记保守软件限位。型号/现状不足时先修证据，不执行置中试错。控制窗口负责脉宽→实际角度标定。

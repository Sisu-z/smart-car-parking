# 赛道与车位视觉规格 TRACK-V2

更新：2026-10-19，按用户实际购买与最新答复修订。状态：库存为`PROJECT-CONTEXT`，采样办法为`DESIGN`，识别/铺收未实测。DEC-024替代TRACK-V1的20mm硬冻结和重复采购要求；本文件路径不变，不另存竞争的“最新版”。

## 统一规格

| 项目 | 统一要求 |
|---|---|
| 背景 | **哑光黑色、均匀无纹理**；印刷图稿目标 `#000000`，不要求实拍RGB固定为0 |
| 道路边界 | **哑光白色、连续实线**，道路左右两条边界均如此；不额外加入黄色中心线 |
| 普通车位线 | 同样的哑光白色连续线，U形车位；不加入二维码、AprilTag或特殊定位图案 |
| 当前试验线宽 | **10mm**，来自已购美纹纸规格；道路边界和普通车位样片先统一用这一卷。不是车道宽度，也不是最终效果保证 |
| 制作检查 | 记录实物宽度与接缝；不虚构商家公差。需要比较时同卷两条并排形成约20mm样本，单独标记，不把不同宽度混成同一采集配置 |
| 胶带 | 用户确认白色、磨砂质美纹纸，宽10mm；具体黏性/可移除时长未验证。先在实际底材小块试贴/揭除 |
| 已购底材 | 黑色哑光1.2m×3m贴纸，带背胶、卷装发货；保留离型纸试铺。材质/厚度未知，不另买黑布或黑纸，也不直接整张粘地面 |
| 底材验收 | 铺开检查皱褶、起拱、翘边和整体滑移；临时固定边缘但不侵入试验区。后续车辆试验还需抓地检查；有底纸不代表一定平整或防滑 |

**无需继续买材料或定制印刷：** 先在已购卷材一部分贴短直道、可修改的曲线段及一个普通U形线框，供静态观察；这不是正式道路/车位尺寸。现有1.2m×3m是材料外形，边缘固定、车身扫掠和安全余量还会占用空间。DIY贴线可以直接成为正式地图，不强制后续付费印刷。

白线不能直接贴在浅色瓷砖上冒充本规格；背景也属于数据分布。绝缘胶带用于电气绝缘，美纹纸用于视觉标线，二者不合并采购/使用。

## 为什么选择这一组

- 黑底白线提供清楚的明暗边界，普通线几何检测无需先依赖复杂语义模型。Duckietown官方场地实践使用黑色背景、哑光标线，要求表面有抓地且不鼓包，可借鉴其材料控制方式。[官方场地规范](https://docs.duckietown.com/ente/opmanual-duckietown/appearance_specifications/tilemap/duckietown-smart-city-tile-map.html)
- **10mm是已购材料的试验起点，不是从轮胎宽推导的最优值。** 可用观察距离、分辨率、安装角和透视才决定图像可辨性。原20mm选择没有本车实拍支持，撤销强制冻结；不得直接套用其他小车/场地的物理线宽。
- “美纹纸”名称不保证不留胶。厂家对可移除时间、表面和使用条件有区分；先试贴至少24小时再揭除检查。可参考[3M表面适用指南](https://multimedia.3m.com/mws/media/1280210O/scotchblue-painters-tape-and-scotch-masking-tape-surface-guide.pdf)，不是推荐把其中蓝色产品用作本项目白线。

## 采样与算法口径

1. 用现有相机静态拍近、中、远三处白线和一个U形车位，包含开灯/日光、阴影与无车位背景；记录实际胶带宽、相机分辨率、安装高度/俯仰和拍摄距离。不要求车辆通电运动。
2. 看远处边界能否分开、阴影中是否仍可检测、亮处是否饱和失去边界；铺收后看皱折、翘边和拼缝。小样先过关再扩大铺设/印刷。
3. **不得把10mm写成固定像素宽或单个全局阈值。** 远近、透视、镜头畸变、曝光会改变图像线宽/亮度；保留尺度容差和几何约束。识别先复用现有OpenCV线段候选与标定/回放，不为统一胶带新增一个训练框架。
4. 拟合需注明用线中心还是边缘；道路净宽、车位可用宽以白线内缘之间的黑色自由区计，不能把线带本身当行驶余量。数据标注、规划和印刷图纸保持同一口径。
5. 主开发先用10mm；远处或斜视失败时保持相机条件一致，对比单条10mm和并排约20mm。检查曝光/焦点/遮挡后才决定是否改宽，保存失败原帧；不因此另买胶带。开发与独立验收样本继续分开。

## 冻结范围与变更

- 已确认库存：白色磨砂10mm美纹纸、黑色哑光1.2m×3m带背胶卷材；黑底白线作为当前视觉口径。
- 未冻结：最终线宽、整图有效布局、道路净宽、弯道半径、车位长宽/数量、拼接位置；这些仍依赖真实包络、转弯能力与视野。不因已买大幅材料就宣称闭合道路与倒库一定装得下。
- 若样片在所需视野下失败，先查焦点/曝光/安装/分辨率，再评估是否改线宽；必须由总监同步本文件、DECISIONS和数据版本后更改。不能算法窗口偷偷按一套、采购/印刷按另一套。

# 赛道与车位视觉规格 TRACK-V1

更新：2026-10-19。状态：`DESIGN`，本轮按用户要求确定材料/配色/线宽。适用于临时贴线、实拍数据与后续印刷图稿；不是整张地图布局设计，也不是视觉实测通过。

## 统一规格

| 项目 | 统一要求 |
|---|---|
| 背景 | **哑光黑色、均匀无纹理**；印刷图稿目标 `#000000`，不要求实拍RGB固定为0 |
| 道路边界 | **哑光白色、连续实线**，道路左右两条边界均如此；不额外加入黄色中心线 |
| 普通车位线 | 同样的哑光白色连续线，U形车位；不加入二维码、AprilTag或特殊定位图案 |
| 实际线宽 | **20mm**，指一整条白色线带的物理宽度，不是车道宽度；道路线、车位线、印刷线统一 |
| 制作检查目标 | 直段实际宽度20mm，允许制作偏差目标±1mm；这是项目要求，不是商家精度保证。收到18/19/24mm规格不要默认为20mm |
| 胶带 | 白色、哑光、低黏可移除美纹纸/美工纸胶带；拒绝米黄、蓝色、亮面或透明覆膜款。先在实际底材小块试贴/揭除 |
| 底材 | 平整、薄型、可铺收的哑光黑色底材；先选小样验证。卷后不起拱，拼缝不形成凸台，不用有绒毛/明显压纹/厚软泡棉的材料直接作基准 |

**先购样，不定制整张地图：** 白色20mm×20m胶带一卷，足够首批局部道路/车位静态样本，不承诺覆盖未设计的整张地图；另备约1m×1m哑光黑底样片（若已有符合要求的材料可直接用）。底材可先询问薄型哑光PVC/地贴供应商取样，但具体产品的平整、附着和轮胎抓地尚未确认，不能只凭“哑光”批准整卷采购。

白线不能直接贴在浅色瓷砖上冒充本规格；背景也属于数据分布。绝缘胶带用于电气绝缘，美纹纸用于视觉标线，二者不合并采购/使用。

## 为什么选择这一组

- 黑底白线提供清楚的明暗边界，普通线几何检测无需先依赖复杂语义模型。Duckietown官方场地实践使用黑色背景、哑光标线，要求表面有抓地且不鼓包，可借鉴其材料控制方式。[官方场地规范](https://docs.duckietown.com/ente/opmanual-duckietown/appearance_specifications/tilemap/duckietown-smart-city-tile-map.html)
- **20mm是本项目的小场地设计选择，不是Duckietown标准。** 后者白线为48mm、标准砖边长61cm；不能直接照搬到用户约15cm宽的小车和1～1.5m宽场地。20mm兼顾局部可辨性与道路/车位边缘占用，是否满足实际观察距离由样片实拍检验。
- “美纹纸”名称不保证不留胶。厂家对可移除时间、表面和使用条件有区分；先试贴至少24小时再揭除检查。可参考[3M表面适用指南](https://multimedia.3m.com/mws/media/1280210O/scotchblue-painters-tape-and-scotch-masking-tape-surface-guide.pdf)，不是推荐把其中蓝色产品用作本项目白线。

## 采样与算法口径

1. 用现有相机静态拍近、中、远三处白线和一个U形车位，包含开灯/日光、阴影与无车位背景；记录实际胶带宽、相机分辨率、安装高度/俯仰和拍摄距离。不要求车辆通电运动。
2. 看远处边界能否分开、阴影中是否仍可检测、亮处是否饱和失去边界；铺收后看皱折、翘边和拼缝。小样先过关再扩大铺设/印刷。
3. **不得把20mm写成固定像素宽或单个全局阈值。** 远近、透视、镜头畸变、曝光会改变图像线宽/亮度；保留尺度容差和几何约束。识别先复用现有OpenCV线段候选与标定/回放，不为统一胶带新增一个训练框架。
4. 拟合需注明用线中心还是边缘；道路净宽、车位可用宽以白线内缘之间的黑色自由区计，不能把线带本身当行驶余量。数据标注、规划和印刷图纸保持同一口径。
5. 主开发与印刷样本按20mm；可用离线缩放/额外样本检查宽度、光照扰动，不必为鲁棒性测试另买一套不同宽胶带。训练/开发样本与独立验收样本继续分开。

## 冻结范围与变更

- 已确定：黑底、白色哑光实线、物理线宽20mm，以及材料检查方式。
- 未确定：整图尺寸、道路净宽、弯道半径、车位长宽/数量、拼接位置；这些仍依赖真实包络、转弯能力与视野。不因本文件下单最终地图。
- 若样片在所需视野下失败，先查焦点/曝光/安装/分辨率，再评估是否改线宽；必须由总监同步本文件、DECISIONS和数据版本后更改。不能算法窗口偷偷按一套、采购/印刷按另一套。

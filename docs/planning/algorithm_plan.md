以下字段/模块路径是正式契约的**提案细化**，不新增协议版本。沿用 m、rad、s；车辆 +x 前、+y 左、yaw 逆时针。现有仿真原点为后轴中心，实车 `base_link` 尚待登记；相机地面测点必须能变换到同一原点。

| 模块 / 建议位置 | 输入 | 输出 / 使用条件 |
|---|---|---|
| 采集与回放，扩展现有媒体工具；实时适配归 #11 | 图像、采集/接收时间及各自时钟域、分辨率、camera/mount/calibration 版本 | 最新一帧及龄期/丢帧诊断；禁止长队列消费旧画面，未同步设备不能直接相减时间戳；缺可信采集时刻/可验证延迟上界时龄期 UNKNOWN，仅静态离线候选验证，不准运动 |

| 局部估计，拟独立 `offline/local_pose.py` | 有方向的里程/轮速、有效 dt、转向标定/估计质量、相机相对观测 | 局部 SE(2) 位姿及误差界/质量；无绝对房间坐标要求，不接受人工起点/车位答案 |
| 任务/搜索，拟 `offline/parking_task.py` | PARK/EXIT/CANCEL、观测、已知空间/龄期、估计质量/底层反馈 | 短段动作或轨迹请求、状态/失败原因；不访问串口/HAL；输出仍须 vehicle 层门控 |
| 规划/跟踪，扩展 `parking.py` 的适配层 | 实测模型、当前位姿、观测生成的目标、安全域与障碍、入口约束 | `(x,y,yaw,direction,curvature)` 路径及可执行时序，速度 m/s、转向 rad；无安全路径返回拒绝，真实底层接口由总监收敛 |

算法组合只保留三种有实质区别的候选，不用评分表代替证据：

| 组合 | 适用证据 / 优势 | 增量与采用条件 |
|---|---|---|
| A：几何感知 + 局部估计 + RS/纯追踪 | 普通线有可重复对比度、入口可观测、短距离机动；现有复用最多 | 首先验证；补语义拒绝、空闲证据、时序/扫掠/任务层。任何关键缺口仍阻塞实车准入 |
| B：同一感知/估计 + 局部 Hybrid A* + 相同跟踪 | 已观察到的可达通路需绕过区域，而所有直接 RS 候选被挡 | 固定上游小范围适配：尺寸/单位/网格一致性、空闲域、预算/取消、入口倒车约束；同场景证明增益再升级。它不能解决盲区或地图未知 |
| C：学习式线/入口提议 + 几何验证 + A 的控制 | A 在路线选择集的地砖/反光/遮挡数据上持续误识别，且有可用公开模型证据 | 另核原作者实现、权重/数据许可证及 X5 实测时延；不本轮选模型/训练。网络置信度不能直接变 FREE，也不能补不存在的后视 |

RS 无解先排查模型/覆盖/未知空间和采样诊断，不自动升级 B。B 需同一输入、相同安全余量的对照：找到可执行路径、限制换向/转向速率、计算耗时和失败退出都达预登记预算，才值得增加维护成本。不是为“更高级”换算法。

## 3. 分阶段具体实现

### 3.1 静态感知与循迹/曲线（M3 可独立；运动依赖 M2）

复用 `ground_view`、LSD 与本地批处理；U 形组合只用于车位，**曲线道路不能直接交给现有直线/U 形检测器**。道路分支在有效鸟瞰区域用 OpenCV 阈值/边缘/连通域得到边界采样，按前向距离分带匹配左右边界，以平滑局部曲线表示。匹配用宽度连续性、方向连续性和历史关联，不能在弯道按任意同 x 两点直接取均值；沿曲线法向配对后取中心，检查整车走廊。线色/材质未确认，阈值仅开发集拟合。丢边短时是否可推定及有效距离须由数据确定，默认失效停止。

用已适配纯追踪输出 `delta=atan(2L*y_target/(x_target²+y_target²))`，前进道路目标在车体前方；随速度/曲率调整前视距离，但前视点必须在可信覆盖内。将路径曲率限制为实测可控范围，按曲率、转向速率、观测距离和停止包络降低速度；持续转向饱和视为几何不可执行，不继续积分“硬拐”。速度目标由 vehicle 层换算轮速，V0 RPM 接口不在算法层偷偷改变。

车位分支先对完整 U 形做米制尺寸/直角/条纹宽度/颜色对比筛选，再做多帧身份关联与入口方向一致性检查。不能靠 U 形和稳定多帧就排除地砖：地砖同样稳定。必须在不同场地负例上评价，记录外观区分依据；等价图案无法区分时输出 AMBIGUOUS。两侧可见但背边缺失只允许关联既有可信车位，并标推定字段；首次只见两平行线不能猜入口或深度。候选与可控制观测用不同适配层，不能直接解除现有实验输出的 `false/UNKNOWN`。

内部过关：静态独立测点验证尺度/符号；留出场景测车道中心误差、车位入口位置/朝向误差与假阳性；回放能定位何时失效。此后经 M2/安全授权，直道→左右圆弧→S 弯，检查外侧车角/内侧轮及停止包络，不只检查中心点。直角方向变化是圆弧/多次调整的几何问题，阿克曼不能原地转 90°；是否纳入及所需过渡空间交总监，不据此定最终地图。

### 3.2 运动估计、帧龄期与空间可用性（M2/M3 接合）

先采用有界局部坐标：每次任务建立任意局部原点，编码器位移与有效转向估计按自行车近似 `d_yaw=ds*tan(delta)/L` 积分；这不是已知起点，也不依赖房间坐标。双驱动轮平均位移能否近似后轴中点须由 #15 的轮位/标定证明，不假定差速转向。舵机命令仅是估计，不等于实测轮角；零点、左右不对称/回差与打滑计入误差。用普通线入口/边界的多帧重观测修正相对几何；沿无限长直线的纵向不可观测，不能将任意直线当完整定位。

保存采集时刻的里程计历史；只有可信采集时刻，或可验证的采集至接收延迟上界及有效时钟关系，才允许将 `T_base(capture)_slot` 经相对运动传播到控制时刻，并保守计入时间不确定性。缺这类证据时观测龄期标 UNKNOWN，仅静态/离线候选验证，不准运动；接收戳和录像 POS_MSEC 都不能冒充真实 capture 时刻做实车运动补偿/准入。标定/帧身份错误、位姿突跳、过期或误差超预算均停。若重新观察可恢复，先确认停稳，再重新评估/规划，不能收到新帧就自动恢复旧目标。帧率/控制频率/超时不从实验 `.02/.25 s` 抄到实车；#11 应提供采集、传输、处理、队列、执行全链路龄期分布。

空间层维护局部 UNKNOWN/FREE/OCCUPIED 及来源/更新时间，与车位几何独立。候选 RGB 基线在鸟瞰分块核地面外观支持，结合原图前景/物体底部和多帧残差标疑占用，遮挡后方与覆盖外保持 UNKNOWN；这只是待验证方法，不提供任意障碍检测保证。FREE 只在已确认地面/障碍类别下由有效观测支持；必须检验书本、低矮物、线外物体、遮挡和反光，不支持的类别为 UNKNOWN。障碍投影不能将离地物体直接按地面单应当真实底边。有人监督不把未知区变成 FREE；动态物体进入或证据过期须重新评估。若现有观测无法证明工作范围安全，由总监组织补观察方案/增补候选，不能凭“没有检测到”放行。

### 3.3 起步不可见的主动找位（M5；先替身输入）

任务层提案：自检/静态观察→搜索→车位评估→接近→倒库→停稳；独立 EXIT 另启出库评估/规划；任意阶段可到 STOPPING/FAULT。搜索是闭环观察行动，不能从测试种子、地图手填坐标或固定时间表取答案。

每步维护已观测区域、候选及访问记录；在新鲜 FREE 域内生成短直行/左右弧动作，用完整扫掠+停止包络筛除，剩余动作按新视野增量、里程/换向代价选择。执行短段→停稳→再观察，目标距离和结束来自反馈。重复观测同一区域无进展、任务时间/里程/重规划预算耗尽，分别报告 SEARCH_EXHAUSTED/NO_SLOT/NO_SAFE_PATH 等候选原因，不无限绕圈。

初始车位不在视野且没有安全弧可改变视角时，固定前视相机可能完全无可执行动作：车尾/侧面转向扫掠不能用前方地面代替证明。此时停止并记录缺哪块覆盖；提出静态扩展观察或增加后/侧视等候选，需 #13 实测、总监询问现实条件后决定。不暗缩随机朝向域，也不装成已成功搜索。搜索替身测试必须有起步看不到车位、同纹理无车位、已观察域断开、重复访问/里程漂移等输入。

### 3.4 在线倒库及独立出库（M4 → M5/M6）

由当次入口端点构造 slot 系：原点入口中点、+x 库内。倒库车头 yaw 通常为库内方向 +π；不是直接用 `slot_inward_yaw_rad` 当车头目标。目标后轴位置按真实前后悬和车位深度计算，要求**全车包络**在库内且有余量，不能固定车位中心或深度偏置。先枚举少量观测生成的入库准备姿态，RS 规划接近/调整/最终倒车；路径都在已观察安全域，未见车位背边时不猜可停深度。

在现有 `plan` 外增加共同的约束验证器：场地/空闲域、车身（含突出件/轮转向）扫掠、误差膨胀、入口跨越、曲率与转向速率、停止/换向。入口要求记录车身多边形从库外穿过入口段的事件：最终入库从首次车身入侵到全车进入期间是负速度方向、不在入口/库内反向；准备阶段不得先前进入库再用一个小倒车段冒充倒库。具体几何事件口径需独立审查，但必须比 `sections[-1]==-1` 强。相邻采样与 cusp（换向点）连接要显式检查，防止分段丢掉危险间隙。

Pure Pursuit 只搜索当前段局部索引窗口，限制进度跃迁；自交/折返和反向段不能跳到未来分支。RS 曲率可突变，必须通过减速/停止调转向或可验证的平滑轨迹满足实测速率，处理后的路径重新扫掠。换向先请求零速/底层禁用，检查连续有效编码器静止、故障和滑行包络，再按底层契约重新使能与新目标；若轮角无反馈，只能使用经验证的等待/估计质量。停止时长不代替物理停稳，CANCEL/失联/观测失效要单独报告请求和停止是否确认。

后视缺口单独门控：倒车若入口/背边和倒车通路逐步离开前视覆盖，里程计只能暂时传播几何，不能证明新障碍没出现。只有预登记静态环境、有效观察龄期与停止/漂移预算共同满足的短段才是候选；不能默认整段倒车盲走。必要的后/侧观测方案未确定时，关联倒车准入保持阻塞，M4 也不能豁免。

完成判据同时检查相对位姿、全车不越库边、有效低速/静止反馈与停车超时；不只检查轴中心。EXIT 重新读取当前停车位姿、入口/出口可用空间，在当前可观测 FREE 区选安全出库目标并规划；不要求回到随机起点，不倒放旧入库路径。通路占用、未知、感知丢失、目标不可达均拒绝/停止。上次泊车成功不能继承为本次通路空闲。

## 4. 空间与误差的条件化核算

`[PROJECT-CONTEXT]` 日常区域宽 1～1.5 m、长 2～3 m；车宽约 .15 m。轴距、车长/悬长、可用余量、半径、相机覆盖/延迟为 UNKNOWN。以下数值都是**敏感性示例**，不是实物参数或最终道路/地图。

自行车近似 `R=L/tan(delta_max)`；左右、前后及负载不同分别测。整圆转弯的外侧角半径约 `R_out=sqrt((R+w/2)^2+max(front_extent,rear_overhang)^2)`。只看 `2R+w` 会漏车头/车尾和误差余量；完整圆扫掠需要看 `2R_out`。多次调整的 U 转不受该整圆必要条件直接判决，须验证具体路径。

| 假设后轴半径 R（m） | `2R+.15`（m，仅整圆外包直径的简化下界） | 与暂报宽度关系 |
|---|---|---|
| .20 / .35 | .55 / .85 | 仍须加悬长、扫掠、边缘/停止余量，不能宣布可行 |
| .50 / .70 | 1.15 / 1.55 | 窄端/宽端已紧或不足；不等于多次调整必然无解 |

道路与车位约束用车身在道路法向的投影，弯道不能仅 `road_width>car_width`。每侧几何余量 g 要覆盖投影/位姿/跟踪误差和停止偏移；任一未知不允许填零。

保守预算提案：`margin >= E_position + r_body*E_yaw + E_tracking + E_age + E_model + safety_reserve`，误差/余量非负、角误差 rad、距离 m，各项用留出实测误差界而非不明置信度。停止域还需加入 `|v|*reaction_age + measured_stop_distance(|v|,direction,load)`；倒车不得用负位移扣减停止空间。reaction_age 覆盖观测采集至停止请求实际生效的延迟，停止距离是生效后至物理停稳的非负实测量，方向/转弯/负载差异不外推。时延内速度变化时用 `∫|v(t)|dt` 或有依据的速度幅值上界乘延迟；按实际运动方向的全车扫掠域检查，不只沿车头方向。龄期/停止距离未知不得填零或放行，速度必须允许在有效可见域内完成停止。使用误差和间隙决定速度、重观察距离及标定要求，不先承诺厘米级。

首轮 r1 Python 算术检查：`v=.1 m/s, age=.1/.3 s` 仅时延位移为 `.01/.03 m`；`.2 m/s,.3 s` 为 `.06 m`。行驶 1 m，固定航向误差 2°/5°的横向分量约 `.035/.087 m`。直行近似中曲率偏差 `.05 1/m` 累积约 `.05 rad` 航向、`.025 m` 横偏；不是实测漂移。转向偏差一阶传播 `Δkappa≈sec²(delta)*Δdelta/L`，再加轴距/轮径/打滑误差，短轴距不能照用全尺寸示例增益。

离散扫掠检查需控制插值误差：区间内车体任一点相对起点的位移上界可用 `Δs_total+r_body*Δψ_total` 约束采样/膨胀，其中 `Δs_total=∫|v(t)|dt` 是累计绝对路程，`Δψ_total=∫|ψ_dot(t)|dt` 是连续展开航向的总变差；不用净位移、wrapped yaw 差或相消后的端点净角差。仅对已证明航向单调的连续路径原语可求 `Σ|Δψ_j|`；普通有限采样端点求和仍可能漏采样间反转。区间行为不能证明时，须用有依据的速度/角速度上界，或能证明行为的进一步细分；否则不宣称连续安全。r_body 使用含轮胎转向/突出件的保守全车包络，仍检查低间隙段和 cusp 连续性。实测参数变化后重算整车包络、入库准备姿态、前视/速度与地图候选，不能只改一处车宽。

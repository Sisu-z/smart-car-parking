# Engineering Logs

按时间记录实际学习、调试和装配。每次只写一份总结，仓库与聊天使用同一正文。日志保留当时状态；最新硬件事实、接口与下一步仍以根目录的现行真源文档为准。

## 写法与交付

沿用下方 9 月 19 日、20 日日志的写法：按实际内容分节，写清本阶段结果、关键过程/原理、踩坑与原因、工程经验及未验证事项。信息少就写短，不凑篇幅；不用第一人称代述。事实、用户报告和推断要分清，不能把旧台架参数写成当前整车已验证参数。

用户说“总结”或“复盘”时，默认将这一份写入 GitHub 并直接发在聊天中，不另写“个人版”。用户明确只要一种交付时，按其要求。

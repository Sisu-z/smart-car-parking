# 2026-10-07 底盘机械装配总结

> 状态说明：[PROJECT-CONTEXT] 本日志记录用户当天实物装配过程。基座和前轮转向结构已基本搭建，但转向中位、左右安全极限、连杆几何和舵机映射仍待正式通电标定，因此不等于机械验收完成。

## 当天结果

约 7 小时完成底盘基座与前轮转向结构的基本搭建。最直观的感受是：机械装配真正耗时的往往不是“拧螺丝”，而是对孔、空间干涉、装配顺序和返工；一个看似简单的舵机螺丝就曾耗约 30 分钟。

## 主要返工原因

- 边看安装视频边做，没有先形成整车装配顺序的全局认知。
- 一些问题只有后续零件装上后才暴露，例如干涉、孔位、螺丝长度、连杆几何和后续工具不可达。
- 前序零件过早锁死，后续发现方向/位置不对时只能拆掉重装。
- 机械机构存在“能装上”和“装得合理”两层要求；仅能连接不代表自由度、极限、受力和后续标定都正确。

## 下次机械装配的标准流程

```text
完整看一遍安装资料
→ 理清零件方向 / 零位 / 孔位 / 螺丝长度 / 装配依赖
→ 零件与紧固件分组
→ 子总成试装
→ 螺丝先手拧 2～3 扣，不终拧
→ 检查自由度 / 全行程 / 干涉 / 后续可达性
→ 全局复查
→ 最后终拧
```

## 成熟工程师真正的提速方式

核心不是“手更快”，而是**返工更少**：

- **先全局后局部**：先看完整装配流程和结构关系，再开始动手。
- **晚锁紧**：位置、方向和后续依赖没确认前只轻锁。
- **早检查**：每完成一个子总成立即检查自由度、干涉、松紧和方向。
- **难拆件最后定型**：一旦覆盖后难以调整的位置，必须在被遮挡前完成验证。
- **运动机构先跑全行程**：转向、连杆等不能只看中间位置，还要检查两端极限和是否接近死点。
- **异常追前序根因**：不要靠后面的连杆长度、软件零点或其它参数硬补前面的装配错误。
- **记录实物差异**：厂家视频/推荐尺寸只是基线，实物更改孔位、镜像安装或连杆长度后必须重新标定。

## 一句话经验

> 机械装配提速的核心不是“做快”，而是“先拉通、晚锁紧、早检查、少返工”。
